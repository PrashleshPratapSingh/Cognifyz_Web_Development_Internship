## Level 1

### Task 1: HTML & CSS

**File:** `Level_1/task1.html`

- Created a webpage with a heading, paragraph, and image using HTML and CSS.
- Built a form with a single input field and a submit button.
- Designed and coded a navigation menu with three links.

**Technologies used:** HTML5, CSS3

---

### Task 2: JavaScript

**File:** `Level_1/task2.html`

- Developed a button that changes its color each time it is clicked using JavaScript.
- Created a greeting message that displays based on the current time of day (Good Morning / Afternoon / Evening / Night).
- Built a basic calculator that adds two numbers and displays the result.

**Technologies used:** HTML5, CSS3, Vanilla JavaScript

---

## Level 2

### Task 1: Front-end Frameworks

**File:** `Level_2/task1.html`

- Built a responsive card component with an image and text using Bulma CSS.
- Implemented a responsive grid layout using Bootstrap 5 that adjusts from 4 columns on desktop to 1 column on mobile.

**Technologies used:** HTML5, Bulma 0.9.4, Bootstrap 5.3

---

### Task 2: Responsive Design

**File:** `Level_2/task2.html`

- Converted a webpage to a responsive layout using CSS media queries at 900px and 640px breakpoints.
- Created a mobile navigation menu that collapses into a hamburger menu on smaller screens using HTML, CSS, and JavaScript.

**Technologies used:** HTML5, Vanilla CSS, Vanilla JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in any web browser to access all task links.
3. Or open task files directly from the `Level_1/` and `Level_2/` folders.

No build step or server required.
