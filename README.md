## Level 2 Tasks

### Task 1: Front-end Frameworks

**File:** `Level_2/task1.html`

- Built a responsive card component using **Bulma CSS**, with an image and descriptive text per card.
- Implemented a responsive grid layout using **Bootstrap 5**, with columns that adjust from 4 on desktop to 2 on tablet to 1 on mobile.

**Technologies used:** HTML5, Bulma 0.9.4, Bootstrap 5.3

---

### Task 2: Responsive Design

**File:** `Level_2/task2.html`

- Converted a webpage to a fully responsive layout using **CSS media queries** (`max-width: 900px` for tablet, `max-width: 640px` for mobile).
- Created a mobile-friendly navigation menu that collapses into a **hamburger menu** on smaller screens using HTML, CSS, and minimal JavaScript for the toggle.

**Technologies used:** HTML5, Vanilla CSS, Vanilla JavaScript

   - `Level_2/task2.html` for Task 2
